# Datenschutzerklärung – Recipe Collection

*Zuletzt aktualisiert: 1. März 2026*

---

## Deutsch

### 1. Verantwortlicher

Diese App wurde als privates Projekt entwickelt. Bei Fragen zum Datenschutz wende dich bitte über GitHub Issues an den Entwickler:
[https://github.com/4Gettt25/Recipe-Colletion/issues](https://github.com/4Gettt25/Recipe-Colletion/issues)

### 2. Welche Daten werden erhoben?

**Diese App erhebt keine personenbezogenen Daten.**

Es werden keine Daten an den Entwickler, an Dritte oder externe Server übertragen.

### 3. Welche Daten werden lokal auf dem Gerät gespeichert?

Folgende Daten werden ausschließlich lokal im Speicher deines Geräts (localStorage) gespeichert:

| Datentyp | Zweck |
|---|---|
| Rezepte (Titel, Zutaten, Beschreibung) | Offline-Nutzung der App |
| IP-Adresse des Heim-PCs | Verbindung zum eigenen Desktop-Server im lokalen Netzwerk |
| Spracheinstellung | Darstellung der App in der bevorzugten Sprache |

Diese Daten verlassen dein Gerät nicht und werden nicht an externe Server oder Dritte weitergegeben.

### 4. Kamera-Nutzung

Die App fragt nach der Kamera-Berechtigung, um einen QR-Code zu scannen. Dieser QR-Code enthält ausschließlich die IP-Adresse deines eigenen Heim-PCs, um die Verbindung zum lokalen Server herzustellen.

- Kamerabilder werden **nicht gespeichert**
- Kamerabilder werden **nicht übertragen**
- Die Kamera wird **ausschließlich** für den QR-Scan verwendet

### 5. Netzwerkzugriff

Die App verbindet sich ausschließlich mit einem Server im **lokalen Heimnetzwerk** (z. B. `192.168.x.x`), der vom Nutzer selbst betrieben wird. Es findet keine Kommunikation mit dem Internet oder externen Servern statt.

### 6. Drittanbieter

Die App verwendet keine:
- Analyse-/Analytics-Dienste (z. B. Google Analytics, Firebase)
- Werbenetzwerke
- Tracking-SDKs
- Nutzerkonto-Systeme

### 7. Kinder

Diese App richtet sich nicht gezielt an Kinder unter 13 Jahren. Da keine personenbezogenen Daten erhoben werden, besteht kein besonderes Risiko.

### 8. Änderungen dieser Datenschutzerklärung

Bei wesentlichen Änderungen wird diese Seite aktualisiert. Das Datum der letzten Aktualisierung ist oben angegeben.

## English

### 1. Data Controller

This app was developed as a private project. For privacy-related questions, please contact the developer via GitHub Issues:
[https://github.com/4Gettt25/Recipe-Colletion/issues](https://github.com/4Gettt25/Recipe-Colletion/issues)

### 2. What data is collected?

**This app does not collect any personal data.**

No data is transmitted to the developer, third parties, or external servers.

### 3. What data is stored locally on the device?

The following data is stored exclusively in your device's local storage (localStorage):

| Data type | Purpose |
|---|---|
| Recipes (title, ingredients, description) | Offline use of the app |
| Home PC IP address | Connecting to the user's own desktop server on the local network |
| Language preference | Displaying the app in the preferred language |

This data does not leave your device and is not shared with external servers or third parties.

### 4. Camera usage

The app requests camera permission to scan a QR code. This QR code contains only the IP address of your own home PC in order to establish a connection to your local server.

- Camera images are **not stored**
- Camera images are **not transmitted**
- The camera is used **exclusively** for QR code scanning

### 5. Network access

The app connects exclusively to a server on your **local home network** (e.g. `192.168.x.x`) that is operated by the user themselves. No communication takes place with the internet or external servers.

### 6. Third parties

This app does not use:
- Analytics services (e.g. Google Analytics, Firebase)
- Advertising networks
- Tracking SDKs
- User account systems

### 7. Children

This app is not directed at children under 13. Since no personal data is collected, there is no particular risk.

### 8. Changes to this privacy policy

This page will be updated if there are significant changes. The date of the last update is shown at the top.
