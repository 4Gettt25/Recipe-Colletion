# Recipe Collection

> **This app is 100% vibecoded.** Every single line of code was generated by [Claude](https://claude.ai) (Anthropic) through conversational prompting. No traditional hand-coding was involved at any point.

A personal recipe manager with a Windows desktop app, Android mobile app, and a local Express/SQLite backend that runs entirely on your own machine — no cloud, no subscription.

---

## Features

- Create, edit, and delete recipes with ingredients, portions, tags, descriptions, and star ratings
- Upload recipe images
- Favourite recipes
- Android app that connects to the desktop over Wi-Fi by scanning a QR code
- Offline support on mobile — save desktop recipes to your phone for use without a connection
- Sync phone-only recipes back to the desktop
- Windows system tray app — runs in the background, starts the local server automatically on launch
- Auto-updates via GitHub Releases (no need to manually download new installers)

## Stack

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript + Vite + Tailwind CSS + shadcn/ui |
| Backend | Express + better-sqlite3 (SQLite, port 3001) |
| Desktop | Electron 40 + electron-builder (NSIS installer) |
| Mobile | Capacitor 8 → Android APK |

## Getting Started

### Prerequisites

- Node.js 20+
- npm
- Android Studio (only needed for Android builds)

### Install dependencies

```bash
npm install
```

### Run in dev mode (browser + server)

```bash
npm run dev
```

Opens the Vite dev server at `http://localhost:5173` with the Express API proxied from port 3001.

### Run as Electron desktop app (dev)

```bash
npm run electron:dev
```

> Note: you cannot run `npm run dev` and `electron:dev` simultaneously — both bind port 3001.

### Build Android APK

```bash
npm run android:sync   # builds frontend and syncs to Capacitor
npm run android:open   # opens Android Studio to build/run the APK
```

## Building & Releasing

### Build Electron installer

```bash
npm run electron:build
```

Output: `dist-electron/Recipe Collection Setup x.x.x.exe`

### Publish a new release to GitHub

1. Bump `version` in `package.json`
2. Create a `.env` file in the project root (already gitignored):

```
GH_TOKEN=your_github_personal_access_token
```

3. Build and publish:

```bash
export $(cat .env | xargs) && npm run electron:build -- --publish always
```

4. Go to [GitHub Releases](https://github.com/4Gettt25/Recipe-Colletion/releases) and publish the draft

Installed apps will detect the new version on next launch and prompt to update automatically.

## Mobile — Connecting to Desktop

1. Open the desktop app → click the gear icon → a QR code is displayed
2. Open the Android app → gear icon → **Scan QR Code**
3. Both devices must be on the same Wi-Fi network

Once connected, desktop recipes appear in the app and can be saved offline. Phone-only recipes can be synced to the desktop via the Settings sheet.
